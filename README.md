# 🎟️ Ticketentra – AI-Powered Ticket Support System

Ticketentra is a full-stack AI-powered support ticketing system built with the **MERN stack** and powered by **Inngest** for background workflows. It offers smart ticket generation, async status handling, and an interactive admin dashboard for managing support requests seamlessly.

---

## 🚀 Tech Stack

| Frontend       | Backend       | Workflow / Queue | Database  | Auth | Styling |
|----------------|---------------|------------------|-----------|------|----------|
| React.js (Vite) | Node.js + Express | Inngest          | MongoDB   | TBD  | Tailwind CSS |

---

## 📦 Features

- ✅ Submit tickets with smart AI prompts
- ✅ Real-time ticket status updates
- ✅ Inngest-powered async workflows
- ✅ Admin dashboard for managing and resolving tickets
- ✅ MongoDB-based storage
- ✅ Scalable & production-ready architecture
